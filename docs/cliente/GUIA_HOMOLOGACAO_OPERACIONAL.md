# Guia de Homologacao Operacional

Ambiente: Homologacao

URL: http://89.116.214.65:3010

## Objetivo

Validar o fluxo operacional do Atenza FieldOps usando os dados de homologacao da Ciperprag.

## Fluxo recomendado

1. Acessar a plataforma e confirmar que o badge `Homologacao` esta visivel.
2. Conferir agenda e equipe vinculada.
3. Gerar OS a partir de um agendamento.
4. Imprimir/visualizar a OS para equipe de campo.
5. Encerrar OS com data, quantidade, tag quando houver e evidencias.
6. Conferir se certificado e historico foram atualizados quando o servico permitir certificado.
7. Conferir medicao com base no periodo do servico executado.
8. Confirmar sugestao de recorrencia quando aplicavel.

## Pontos de atencao

- Homologacao nao deve ser usada como producao.
- Divergencias em OS, certificado, contrato, proposta ou medicao devem ser registradas com print e numero do documento.
- Alteracoes visuais nos documentos devem ser validadas por PNG antes de aprovacao.
