# Release 2026-07-06 - v0.3.0 Homologacao

## Objetivo

Entregar a Etapa 3 de 8: integracao comercial para operacional.

## Entregue

- Contrato comercial vigente passa a sincronizar contrato operacional executavel.
- Proposta aprovada, ao gerar contrato, tambem cria os contratos operacionais por servico.
- Contrato operacional recebeu origem comercial, item de origem, servico do catalogo, numero comercial, vigencia e frequencia.
- Locais ativos do cliente e tags de equipamentos ativos alimentam o contrato operacional.
- Agenda passou a listar contratos operacionais ativos.
- Tela comercial mostra status de integracao operacional.
- Migracao versionada `014_commercial_operational_contract_bridge.sql`.

## Validacao

- Teste funcional local com proposta temporaria aprovada, geracao de contrato e criacao de contrato operacional.
- Dados temporarios removidos apos o teste.
- Numeracao de contrato restaurada para o maior contrato real da homologacao.
