# Release 2026-07-06 - v0.4.0 Homologacao

## Resumo

Release de aderencia documental visual para aproximar medicao, proposta e contrato dos modelos usados pela Ciperprag, mantendo a aplicacao em base de homologacao.

## Entregue

- Medicao impressa com layout mais proximo do modelo original: cabecalho institucional, titulo em destaque, dados do contratante, itens medidos, total, forma de pagamento, local de entrega e assinatura.
- Proposta/contrato impressos com estrutura documental: cabecalho, dados do contratante, tabela de servicos, condicoes comerciais e assinaturas.
- Regra de impressao dedicada para exibir somente o documento, sem cabecalho/menu/tela da aplicacao.
- Evidencias PNG dos modelos originais e dos documentos atuais.

## Evidencias

- `docs/evidencias/etapa4_originais`
- `docs/evidencias/etapa4_atual/medicao-atual.png`
- `docs/evidencias/etapa4_atual/contrato-proposta-atual.png`

## Parcial ou nao feito nesta release

- PDF server-side real permanece na Etapa 6.
- Ajuste fino final de OS e certificado permanece vinculado a QA visual e PDF server-side.
- Versionamento formal de templates de documentos permanece na Etapa 6.

## Validacao recomendada

- Emitir uma medicao em homologacao e usar o botao Imprimir.
- Abrir contrato/proposta comercial e usar o botao Imprimir.
- Conferir se a tela do sistema nao aparece junto na impressao.
- Comparar visualmente com as evidencias PNG desta release.
