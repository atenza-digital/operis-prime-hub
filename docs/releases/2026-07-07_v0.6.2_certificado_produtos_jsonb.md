# Release interna - v0.6.2 Certificado com Produtos Detalhados

Data: 07/07/2026

Ambiente: Homologacao

## Motivo

Durante a execucao tecnica E2E na VPS, o encerramento de OS falhou ao emitir certificado quando o servico possuia `produtos_detalhados` armazenado como strings JSON em array legado.

## Entregue

- Normalizacao backend de arrays JSON para aceitar objetos, strings JSON e strings simples.
- Emissao de certificado passa a gravar `produtos_detalhados` como JSONB valido.
- Cadastro/edicao de servicos tambem passa pela mesma normalizacao antes de gravar produtos detalhados.
- Versao atualizada para `0.6.2`.

## Validacao esperada

- Encerramento de OS com certificado nao deve falhar por `produtos_detalhados`.
- `npm run homologation:e2e-vps` deve avancar ate o encerramento de OS com certificado.

## Observacao posterior

- A normalizacao JSONB foi confirmada durante o E2E tecnico.
- O mesmo E2E encontrou uma falha seguinte no registro de auditoria do encerramento de OS, corrigida na versao `0.6.3`.
