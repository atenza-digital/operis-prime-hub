# Release interna - v0.6.3 Encerramento de OS com Certificado

Data: 07/07/2026

Ambiente: Homologacao

## Motivo

Durante o E2E tecnico na VPS, o encerramento de OS com certificado automatico falhou por referencia incorreta de variavel no registro de auditoria.

## Entregue

- Corrigida referencia `certificadoHash` para `certificateHash` no fechamento de OS.
- Versao atualizada para `0.6.3`.

## Validacao esperada

- Encerramento de OS com certificado automatico deve concluir.
- `npm run homologation:e2e-vps` deve continuar ate medicao/recorrencia.
