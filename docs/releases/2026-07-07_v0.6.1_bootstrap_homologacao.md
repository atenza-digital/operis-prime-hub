# Release interna - v0.6.1 Bootstrap de Homologacao

Data: 07/07/2026

Ambiente: Homologacao

## Motivo

O smoke tecnico da VPS identificou erro HTTP 500 no `/api/bootstrap` apos login. A causa era uma incompatibilidade entre o codigo publicado e o schema real da tabela `tenants`: o backend buscava `tenants.nome`, enquanto a base usa `nome_fantasia` e `razao_social`.

## Entregue

- Corrigida consulta de configuracao da empresa para usar `COALESCE(t.nome_fantasia, t.razao_social, t.slug)`.
- Versao atualizada para `0.6.1`.
- Smoke tecnico da VPS mantido como verificacao antes de liberar testes assistidos.
