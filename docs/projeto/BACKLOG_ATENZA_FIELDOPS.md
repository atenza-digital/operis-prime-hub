# Backlog consolidado - Atenza FieldOps

Prioridades:

- P0: bloqueador para producao.
- P1: essencial para operacao confiavel.
- P2: importante para qualidade e escala.
- P3: refinamento ou evolucao posterior.

Status padrao: proposto, aguardando aprovacao antes de implementacao.
